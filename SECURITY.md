# Security policy

## Supported versions

The latest release of each repository receives security fixes. Older releases are not patched: update to the latest one.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you find a possible security flaw in any repository of the Electro Hobby 3D ecosystems (firmware, authentication, machine safety), report it privately:

1. Email `electrohobby3d@gmail.com` with the affected repository and version, a description of the problem and the steps to reproduce it.
2. You will get a first answer within 48 hours.
3. We follow coordinated disclosure: please wait for a fix before making anything public.

Never include credentials, tokens or private network details in a report.
