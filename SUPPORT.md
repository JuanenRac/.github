# Support

* Questions about the software: write to `electrohobby3d@gmail.com` or watch [youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d).
* Bugs, improvements and documentation corrections: open an issue in the repository the problem belongs to and choose one of the forms. A bug report asks for the output of `eh3d-updater --cli status --offline`, which lists the version of every installed repository of the suite.
* Security problems: do not use issues; follow the security policy.
